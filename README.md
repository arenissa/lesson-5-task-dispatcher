# Диспетчер входящих задач

Учебный проект продолжается после урока 4.

В предыдущем уроке мы настроили OpenCode, общие правила проекта,
разрешения и slash-команды. Теперь нужно превратить поток из 24
входящих запросов в первую рабочую версию приложения «Командный центр».

## Стартовое состояние урока 5

- `AGENTS.md` — общие правила проекта и критерии готовности;
- `opencode.json` — базовые разрешения OpenCode;
- `input/requests.md` — 24 исходных запроса из пяти каналов;
- `output/task-board.md` — небольшая сводка, оставшаяся после урока 4;
- `.opencode/commands/` — две slash-команды из урока 4.

В стартовой версии ещё нет:

- проектных субагентов;
- Skill для операционного дашборда;
- папки `app/`;
- готового приложения.

Эти элементы должны появиться во время практики урока 5.
